# Frontend Implementation Plan — Index

**Goal:** Build the complete frontend for tpicap-blotter — a real-time trade blotter SPA with live WebSocket updates, P&L calculation, full CRUD via forms, and a filtered/sorted AG Grid table.

This plan is split into 9 independent task files. Each file is self-contained: it carries the full Global Constraints section, the relevant Review Focus items, and all step content needed to implement and test that task without opening any other file.

## Task Files

| # | File | Description |
|---|------|-------------|
| 1 | [2026-11-11-frontend-01-scaffold.md](2026-11-11-frontend-01-scaffold.md) | Bootstrap the Vite + React + TypeScript project with QueryClientProvider, ErrorBoundary, and the Vitest test harness |
| 2 | [2026-11-11-frontend-02-api-layer.md](2026-11-11-frontend-02-api-layer.md) | Build the typed REST API client functions (`fetchTrades`, `createTrade`, `amendTrade`, `cancelTrade`) and the `useTrades` query hook |
| 3 | [2026-11-11-frontend-03-websocket-hook.md](2026-11-11-frontend-03-websocket-hook.md) | Implement `useWebSocket` with exponential backoff reconnection, live cache updates for trades and prices, and reconnect invalidation |
| 4 | [2026-11-11-frontend-04-pnl-formatters.md](2026-11-11-frontend-04-pnl-formatters.md) | Implement `calculatePnl`, all display formatters (`formatCurrency`, `formatPrice`, `formatTimestamp`, `formatQuantity`), and `usePrices` |
